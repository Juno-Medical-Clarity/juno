## Implementation issues

### BLOCKER: `tests/routes/__init__.py` shadows `backend/routes` package

- **File:** `/root/projects/juno/backend/tests/routes/__init__.py` (empty, 1 line)
- **Cause:** pytest (in its default `prepend` import mode) inserts `tests/` onto `sys.path` so that test modules can be imported. This makes Python find `tests/routes/__init__.py` before `backend/routes/__init__.py`. The conftest's `from routes import all_blueprints` then resolves to the empty test `__init__.py` and raises `ImportError: cannot import name 'all_blueprints' from 'routes'`.
- **Fix (Option A — minimal):** Add `importmode = "importlib"` to `[tool.pytest.ini_options]` in `pyproject.toml`. Verified: with `--import-mode=importlib`, all 429 tests pass.
- **Fix (Option B — cleaner):** Add `pythonpath = [".", ".."]` to `pyproject.toml` (pytest ≥ 7 feature) and remove the per-file `sys.path` bootstraps. Still need `importmode = "importlib"` to prevent the shadowing.
- **Severity:** CRITICAL. The suite is completely un-runnable by default, including in any CI pipeline.

### FAILING TEST: `test_app_observability.py::test_register_sink_called`

- **File:** `/root/projects/juno/backend/tests/utils/test_app_observability.py:14`
- **Error:**
  ```
  AssertionError: Expected a JunoSink to be registered at app startup
  assert False
   +  where False = isinstance(<utils.markers.sinks.InMemorySink object at 0x…>, <class 'utils.markers.sinks.JunoSink'>)
  ```
- **Cause:** The test checks that after `import app`, the global marker sink is a `JunoSink`. But due to test isolation ordering (another test earlier in the session calls `register_sink(InMemorySink())` and that overwrite persists because the sink is a module-level global), the sink is `InMemorySink` when this test runs. This is a test isolation problem: the sink registration is not reset between tests.
- **Severity:** Medium. The test logic is correct in intent but fragile — it depends on test execution order and the fact that `app` was not yet imported when this test runs. In the `--import-mode=importlib` run, other tests in `test_code_markers.py` call `register_sink(InMemorySink())` before this test, poisoning the global state.
